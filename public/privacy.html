Privacy Policy

Personal rclone Google Drive client · Effective 2026-09-11

What this application is

This is a personal, single-user configuration of rclone, an open-source command-line program, running on computers owned or used by the developer. It uses a private Google OAuth client so that the developer can mount and access their own Google Drive from their own machines. It is not a product, service, or website offered to other people, and it has no user accounts, no backend servers, and no shared infrastructure.

Data it accesses

When the developer signs in with their own Google Account, the application requests the Google Drive scope (https://www.googleapis.com/auth/drive) so that rclone can list, read, and write files in that same account's Drive. Only the Google Account that performs the sign-in is accessed. No other person's Google data is requested or received.

How data is used and stored

  • Drive file contents are transferred directly between Google's servers and the developer's own computers. They are not sent to any third party, server, or analytics service.
  • The OAuth token issued by Google is stored locally in the rclone configuration file on those computers, with access restricted to the owning operating-system user.
  • A local, temporary file cache may be kept on disk to support the mounted filesystem. It lives only on the developer's own machines.
  • No Google user data is sold, shared, transferred to others, or used for advertising, profiling, or training machine-learning models.

Limited Use disclosure

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and revocation

The stored OAuth token is kept only while the setup is in use, and is deleted when the configuration is removed. Access can be revoked at any time at myaccount.google.com/permissions, which immediately invalidates the token.
